# V3 集成验收（2026-09-08）

## 已接通的主流程

安全说明 → 选择保加利亚分腿蹲 → 固定训练腿/目标 → 机位和相机权限 → 观察三次校准动作 → 训练计数及文字/语音 → 结束确认 → 多问题总结和对应行动建议 → 查看各次证据 → 再做一组或保存会话 → 历史重读/删除。

- P0FlowModel 是 V3 主入口唯一业务编排；旧 AppModel/Views 暂保留源码但不再创建旧模型。
- CameraPreview 使用 AVCaptureSession。默认 Apple Vision 2D；旋转后的竖屏缓冲区按 up 处理，避免重复旋转。
- 多人或没有人体时不选取第一个人进行判断，返回无有效关键点，暂停分析。
- 校准和训练的平滑方式、回到顶部阈值一致，避免校准动作在训练阶段无法计数。
- 中断、低质量画面不拼接半次动作。完成重复保留，重启恢复使用结构化草稿。
- 每组保留全部成立问题；总结按三种规则归并，展示相应行动建议。置信度不展示为准确率。
- 会话使用稳定 UUID；SwiftData 保存各组 JSON，兼容旧单组记录。提交成功而草稿未清除时，重开优先采用已保存会话，避免重复。
- 首组开始后固定会话设置。需要换腿/目标时先保存，再新建会话。
- 设置持久化语音开关；关闭语音不关闭文字。真实相机使用时禁止自动息屏。
- 页面目录入口隐藏，避免用户跳过实际业务操作进入虚假的成功状态。

## 自动检查

- 14 个核心测试：校准、完整计次、部分动作、低置信度、证据追踪、提示冷却、主动中断、恢复编号、关闭语音时文字事件。
- 4 个 iOS hosted 集成测试：三次观察校准→训练计数；两组→保存→新模型重读→证据→删除；草稿重读→保留次数且不拼接半次；草稿写失败保留内存数据并报错。
- Xcode 26.6、iOS 26.5 arm64 Simulator 构建。运行入口为 Scripts/verify.sh，设置 COACH_TEST_SIMULATOR 后额外执行 App 测试。
- 测试姿态是合成输入，仅用于检验软件逻辑。没有测得真实准确率。
- 模拟器手动检查：启动页→首页→历史空态→草稿详情→恢复时相机不可用提示。确认使用真实本地计数和草稿时间；未生成模拟训练次数。

## 真机仍需完成

目前未发现连接的 iPhone，以下不标记为通过：

1. 后置相机方向、全身关键点、左右训练腿分别校准和计数。
2. 连续完成三次校准，再做两组；检查语音时机、文本、次数与实际动作一致。
3. 遮挡、离开画面、另一人入镜、切后台和锁屏：不误计，完成次数保留。
4. 杀进程重开草稿、保存后重开 App、删除后重开确认；升级旧数据库。
5. VoiceOver、大字号、减少动态效果、音频中断，以及低端机发热/耗电/延迟。
6. 用教练复核的样本分别统计每条问题规则的误报、漏报、计次误差；未达到验收门槛前不宣称专业准确。
