# 徒手深蹲：自动站稳、计次与回放测试

2026-10-15。本轮先验证个人开发者能够反复独立测试的最小闭环：站稳建立起始参考 → 完整起落计次 → 暂停、结束及保存 → 用固定录像或关键点序列重复分析。

## 使用流程

首页开始新训练，打开相机；固定手机，从身体侧面拍摄，肩、髋、膝、踝完整入镜。自然站直并保持约 2 秒，检测成功后语音提示并自动进入计次，无需走回手机点击开始。下蹲再站回起点算一个周期；看不清关键点时放弃半次动作，保留已完成次数。脚的位置或机位显著变化时重新建立站立参考。

训练中可以暂停、继续、结束和保存。总结显示完整周期数，明确说明当前没有动作标准度评分。旧的保加利亚分腿蹲历史和草稿保留原动作身份及原流程，新建训练默认为徒手深蹲。

个人中心 → 录像回放测试：

- 导入「文件」中的本地视频，视频开头保留自然站立阶段；限制 3 分钟、500 MB。视频经解码、Apple Vision 和同一计次状态机分析，支持播放查看及重复分析。
- 内置 3 次样本是明确标注的合成关键点序列，用于验证流程，不能代替真人录像准确率评估。
- 也支持版本 1 的 `PoseReplayFile` JSON，包含 `version` 和 `frames`，时间戳须严格递增；限制 30 MB、100000 帧。帧结构与 `PoseObservation` 一致，包含图像宽高、引擎版本和关键点。
- 回放不会写入训练历史。导入内容复制到本地临时目录，关闭、更换或取消时清理；不上传。

## 实现边界

站稳判断使用真实帧时间：连续约 2 秒、至少 16 帧、相邻间隔不大于 250ms，并检查髋与踝的位置波动及身体比例变化。参考使用窗口中位数；进入计次后冻结，避免下蹲动作被吸收到站立基线。

计次同时使用相对躯干长度的髋部下降、膝关节屈曲、回升及回到站立起点。坐标先按视频宽高比校正，再计算角度和距离。阈值是本轮计次启发式规则，未经过专业动作标注集验证，不作为深蹲技术或安全标准。

没有新增训练视频自动录制；目前通过已有录像导入回放。当前模拟器无法初始化 Vision 人体姿态请求，因此模拟器 UI 使用明确标注的合成姿态，真实视频推理在 iPhone 验证；视频导入失败会明确显示原因。

## 已完成验证

- 核心：22 项通过，覆盖站稳时间、稀疏帧、身体移动、竖屏角度、3 次完整周期、微动不计次、遮挡与暂停不拼接半次、机位变化保留已完成次数。
- 模拟器集成：17 项通过、5 项条件跳过，0 失败。包括自动进入计次、保存动作身份、关键点回放 3 次和非法时间戳拒绝。视频解码测试用实际 H.264 视频和空姿态探针；不将其说成模拟器已执行 Vision。
- 原生模拟器手动走通：首页 → 设置 → 相机 → 自动站稳 → 计次 → 暂停 → 低质量恢复 → 结束 → 总结 → 保存 → 个人中心 → 回放 3 次 → 再次分析 → 系统文件选择器打开及取消。保存的 43 次来自持续合成输入，仅是流程证据。回放前后个人中心仍为 1 次训练、43 次动作。
- 真机新增集成：自动站稳计次保存、实际视频解码并调用 Apple Vision 两项通过。40 帧无人的测试视频得到 0 次，说明解码与推理链可运行且该空视频没有误计；不能据此推导真人计次数准确率。

相机连续性回归与最终安装回执见 `Docs/INTEGRATION-STATUS.md` 本轮记录。真人连续深蹲、遮挡及不同拍摄条件下的识别准确率仍需实际样本验收。
