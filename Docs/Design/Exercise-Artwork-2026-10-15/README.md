# 保加利亚分腿蹲小人图标

根据用户确认，保留简洁的小人图标风格，撤回真人图片方案。使用原生 SwiftUI Canvas 绘制矢量图形，无位图资源和图片解码。

姿态特征：圆形头部、微前倾躯干、前腿屈膝且脚落地、后腿屈膝且后脚搭在训练凳上；无杠铃或哑铃。统一用于首页、训练设置、动作介绍、机位/校准说明和历史训练缩略图。图标颜色沿用页面深绿/浅色体系。

实现：`App/DesignSystem.swift` 的 `CoachSplitSquatIcon`。

## 验证

- Simulator 与 iPhone Debug 构建成功；最终界面使用原生矢量小人，真人位图未打包。
- 在 iPhone 17 Pro Max 模拟器上检查：首页、训练设置、机位说明、历史列表的图标；已走通设置 → 相机 → 三次校准 → 第 1 组（4 次模拟动作）→ 总结 → 保存 → 首页 → 历史。
- 模拟器使用明确标记的合成姿态输入，只验证页面流程，不代表真实姿态识别精度验收。
- 最终版已覆盖安装到连接的 iPhone 15 Pro Max，保留原有训练数据。
- 界面截图见 screenshots/。

## 小尺寸修订（最终版）

用户要求保持原来的小图标比例，接近 Apple Watch 运动图标的紧凑风格。首页由 88pt 收回 40pt；设置标题 28pt；历史行 28pt 图标放在原来的 36pt 底座内。说明页移除 200pt 大图，改为标题旁 32pt 小图标。凳子使用同色以提高小尺寸辨识度。

模拟器已检查首页和训练设置的实际显示与布局；Simulator/iPhone 构建成功。最终截图为 `screenshots/05-compact-home.jpg`，前面的大图版本仅作迭代记录。
