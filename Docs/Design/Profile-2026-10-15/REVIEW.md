# 个人中心设计与可用性调整

## 实际发现

旧版入口能进入，并非所有功能都失效；主要问题是页面组织和操作预期：

- 导航标题与内容大标题重复，Form 中又放大块说明，挤占首屏。
- “没有账号 / 没有云同步 / 没有订阅”占据主区域，缺少围绕用户训练进度的信息。
- “默认训练腿”只是当前训练腿的只读展示，不是可保存的默认偏好，容易误导。
- 设置详情仍有底部标签栏，但“我的”不高亮；另有返回与完成两个出口。
- 语音、隐私、版本、记录信息混排，难以理解哪些能改、哪些只是说明。

## 最终设计

- 我的：单一标题；训练积累卡展示已保存训练数、完整动作总数、最近训练日期和历史入口。未保存训练不计入统计。
- 训练偏好：语音与提示、机位与校准。副标题显示真实语音状态。
- 数据与应用：隐私与训练数据、关于。底部仅保留简短的本机保存说明。
- 语音与提示：原生 Form，开关立即保存；文字提示和系统动态效果是明确的只读状态。训练腿/目标在每次训练开始时选择。
- 隐私：画面处理、保存内容、设备存储、记录管理分组；管理入口直接进入历史标签。
- 关于：原生弹层，版本从 Bundle 读取。
- 详情页只有返回入口；关于/帮助弹层用完成关闭。
- 不新增虚构账户、会员、打卡或云同步，也不加入无法执行的反馈按钮。
