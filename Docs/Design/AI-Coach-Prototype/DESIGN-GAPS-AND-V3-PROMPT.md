# AI 动作教练 v3 设计缺口与生成 Prompt

## 结论

v2 的 33 张画板已经能够表达端侧训练主流程，但还不能单独作为 Production 实现规格。v3 需要保留现有视觉系统，修正训练会话与训练组语义，并补齐真实设备异常、组后完整指导、Gemini 高级复盘、付费权益、数据生命周期和无障碍状态。

## 一、需要修订的现有设计

### 1. 入口与导航

- 合并或明确“训练入口页”和“产品首页”的职责，避免两个首页并存。
- P0 的“我的”页面不展示账号、云同步和订阅入口；这些能力只能出现在明确标注为 P1 的高级档流程中。
- 动作任务内隐藏底部导航；离开训练时必须有结束、保存或放弃的明确结果。

### 2. 训练会话、训练组与校准

- 一个训练会话包含多组训练。
- “再做一组”复用动作、训练腿、训练目标和本次会话的校准基线，不回到完整配置或重新校准。
- 更换动作、训练腿或训练目标时，应提示这会结束当前会话并要求重新校准。
- 补充“下一组准备”页面或状态，显示沿用的配置和校准状态。
- 校准文案必须说明它是个人参考，不认证动作正确或安全。

### 3. 重复动作与总结术语

- 用“计数重复”“稳定重复”“问题重复”“未计数尝试”替代含义模糊的“有效动作”。
- 有动作问题的完整重复仍然计数。
- 单次重复可以记录多个问题，但实时最多播放一个教练提示。
- 单次动作详情要展示该重复的全部问题，而不是只显示第一个问题。

### 4. Summary + Action List

- 稳定组总结：展示次数和表现；Action List 为空，不编造建议。
- 问题组总结：聚合全部成立问题，显示频率、趋势、可信度和证据入口。
- Action List 为零到三项，按频率、可信度、训练目标和动作依赖关系排序；一种问题最多对应一项行动。
- 明确区分“端侧观察事实”“规则或模型判断”“面向下一组的建议”。
- 保存对象需要明确是训练组摘要；历史中按训练会话组织多个训练组。

### 5. 历史

- 历史列表显示训练会话，而不是把每一组都称为一次训练。
- 训练会话详情显示动作、训练腿、目标、校准版本和所包含的训练组。
- 每一组可展开组总结、重复动作、问题证据和 Action List。
- 补充未保存、保存中、保存失败、存储空间不足、删除失败和删除成功状态。

## 二、端侧 Production 必须新增的状态

### 1. 权限与系统生命周期

- 摄像头已经授权，直接进入机位检查。
- 从系统设置返回后权限已恢复。
- 从系统设置返回后仍未授权。
- App 进入后台、锁屏、来电或系统中断，相机分析暂停。
- 返回前台后可恢复同一训练组，或者在无法恢复时保留已完成重复。
- 麦克风或语音输出中断不影响计数；使用文字提示降级。
- 屏幕方向不符合要求时提示恢复竖屏。

### 2. 画面与输入范围

- 人体太近、太远、头部出框、脚部出框、遮挡、光线过暗、逆光。
- 不是纯侧面、训练腿与配置不一致、多人入镜。
- 识别置信度不足时暂停，不计数、不提示。
- 画面恢复后自动继续，并告诉用户暂停期间没有计数。
- 明确的“不支持当前场景”状态，不让模型猜测。

### 3. 设备与引擎

- 设备过热，分析暂停并保留已完成重复。
- 低电量或低电量模式下的性能降级说明。
- 摄像头被其他应用占用。
- 姿态模型加载失败、推理持续失败、模型版本不可用。
- 可重试故障与不可恢复故障使用不同操作。

### 4. 退出与恢复

- 训练中主动退出：继续训练、结束本组并查看总结、放弃本组。
- 放弃包含已完成重复的训练组时二次确认。
- App 异常退出后重新打开：恢复草稿或放弃草稿。
- 训练组结束但摘要尚未保存时离开：保存、暂不保存、取消离开。

## 三、P1 Gemini 高级复盘需要新增的完整流程

高级复盘只在训练组结束后异步运行，不参与实时计数或实时口令。基础端侧总结始终可用。

### 1. 入口与权益

- 在组总结中展示“高级深度复盘”入口，并解释它与基础总结的差异。
- 高级能力介绍和价格页面。
- StoreKit 购买进行中、购买成功、用户取消、购买失败。
- 恢复购买进行中、成功、没有可恢复购买、失败。
- 权益过期或退款后的状态。
- 没有账号时仍可在当前 Apple ID 设备上恢复购买；不要承诺自建跨平台账号同步。

### 2. 上传前隐私与同意

- 明确列出默认发送内容：动作配置、逐次指标、问题证据、模型和规则版本、少量关键帧。
- “附加短视频”必须是独立、默认关闭的选择。
- 显示为什么需要这些数据、发送给谁、保留多久以及如何删除。
- 用户拒绝云端处理时返回端侧总结，不阻塞训练结果。
- 对包含他人、镜子中他人或敏感环境的画面给出提醒。

### 3. 异步任务状态

- 正在准备结构化数据和关键帧。
- 正在上传，显示进度和取消入口。
- 已排队、正在分析、App 可安全离开。
- 无网络、弱网络、上传中断、请求超时。
- Gemini 暂时不可用、服务端错误、速率限制、当日额度用尽。
- 自动重试、手动重试和退回基础总结。
- App 重启后恢复未完成任务。

### 4. 高级复盘结果

- 顶部保留端侧计数和客观证据，不能被 Gemini 改写。
- 分区显示：已验证观察、AI 综合解释、不确定或无法判断。
- 显示全部成立问题、跨重复趋势和最多三项 Action List。
- 对每项结论提供证据入口，能回到具体重复和关键指标。
- Gemini 与端侧判断冲突时，显示“需要复核”，不能静默覆盖端侧结果。
- 证据不足时给出“无法可靠完成高级复盘”，不生成猜测性建议。
- 显示分析模型版本、分析时间和免责声明。

### 5. 云端数据生命周期

- 云端数据删除成功、删除失败和重试。
- 高级复盘记录保存在本机还是云端必须清楚区分。
- 自动删除时间和立即删除入口。
- 删除云端数据不应误删本地训练摘要，反之亦然。

## 四、无障碍与内容要求

- 为首页、配置、校准、实时训练、暂停、组总结、高级复盘各提供至少一张最大 Dynamic Type 示例。
- 为所有关键页面标注 VoiceOver 阅读顺序和控制名称。
- 实时状态不能只依靠绿色、黄色或红色；同时使用文字和图标。
- Reduce Motion 下取消脉冲、骨架闪动和位移动画。
- 语音关闭或音频不可用时，所有提示均有等价文字反馈。
- 训练中的核心触控目标至少 52 pt，其他目标至少 44 pt。
- 文案使用“观察到”“证据不足”“无法可靠判断”，避免“诊断”“一定错误”“会受伤”等医疗或绝对化表达。

## 五、设计交付物要求

- 保留 `ai-action-coach-prototype-v2.html`，不要覆盖。
- 新建 `ai-action-coach-prototype-v3.html`。
- 新建准确识别所有内嵌画板的 `DESIGN-MANIFEST-v3.json`。
- 新建 `SCREEN-STATE-MATRIX.md`，每个状态记录进入条件、主要信息、主操作、次操作、下一状态、失败恢复、是否需要网络和无障碍说明。
- 新建 `FLOW-MAP-v3.md` 或等价可视化，分开表示 P0 端侧流程和 P1 高级复盘流程。
- 新建 `V2-TO-V3-CHANGELOG.md`。
- 所有画板使用 iPhone 393 × 852 pt 主尺寸，并验证 360 × 800、390 × 844、430 × 932；不要套用桌面 Web 导航或响应式网站结构。
- 所有新页面接入可点击原型，不允许只生成孤立静态画板。
- 不实现 Swift、后端或业务代码。
