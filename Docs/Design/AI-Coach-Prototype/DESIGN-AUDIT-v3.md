# AI 动作教练 v3 设计完整性审计

审计日期：2026-08-31

## 结论

v3 已覆盖当前已确认的 P0 产品边界和 P1 Gemini 高级复盘方向，没有发现需要新增页面才能开始 P0 工程拆解的功能缺口。

当前剩余内容不是“漏设计”，而是五项尚未决定的商业与服务参数。它们已在相关页面显示为待产品确认，不应由设计稿伪造具体数值。

## 已覆盖能力

1. 会话与多训练组：动作、训练腿、目标、校准基线为会话级；组间复用且修改触发重校准规则。
2. 实时训练：端侧计数、问题识别、单一即时提示、证据不足时无法判断。
3. 总结与行动：记录多个问题；输出组总结、完整证据和最多三条下一组建议。
4. 画面质量：远近、出框、遮挡、过暗、逆光、非侧面、训练腿不符、多人入镜。
5. 系统异常：后台、锁屏、来电、音频中断、前台恢复、过热、低电量、相机占用、模型加载/推理失败。
6. 本地数据：草稿恢复、保存中/失败/成功、空间不足、历史空态、会话/组详情、删除确认/失败/成功。
7. 隐私与无障碍：端侧处理、视频默认不保存、最大 Dynamic Type、VoiceOver、Reduce Motion、等价文字、非颜色状态。
8. P1 高级复盘：StoreKit、明确同意、最小上传、短视频独立 opt-in、异步任务、后台通知、无网/超时/服务/额度异常、结果分层、冲突、不确定、云端保留和删除。

## 明确不在第一版

- 账号系统。
- 跨设备云同步。
- 社交、排行榜或教练人工复核平台。
- 实时云端/Gemini 动作判断。
- P0 订阅或云端依赖。
- 默认保存完整训练视频。
