# AI 动作教练 v2 → v3 Production Changelog

## 审计结论

审计对象是 `ai-action-coach-prototype-v2.html` 内嵌的 **33 张画板**，不是把两个 HTML 文件误认为两个产品页面。v3 将信息架构从“单组演示 + 若干孤立异常”改为“会话级多组 P0 端侧产品 + 独立 P1 异步复盘”。

- v2 画板：33
- v3 状态画板：98（P0 69，P1 29）
- 组件状态：18
- 主画板：393 × 852 pt；验证尺寸：360 × 800、390 × 844、430 × 932

## 新增

v3 新增 65 个没有 v2 一对一来源的 Production 状态，覆盖以下类别：

- **会话与多组：** `P0-SESSION-GROUPS`、`P0-NEXT-SET-READY`、`P0-SESSION-COMPLETE`。
- **系统恢复：** 后台、锁屏、来电、音频中断、前台恢复。
- **设备与模型：** 过热、低电量、相机占用、模型加载和推理失败。
- **草稿与本地事务：** 放弃本组、保留完成重复、恢复草稿、保存和删除完整状态。
- **无障碍：** 最大 Dynamic Type、VoiceOver 顺序、Reduce Motion、非颜色状态表达、语音关闭等价文字。
- **P1 高级复盘：** StoreKit、数据同意、最小上传、异步任务、网络异常、结果分层、冲突复核和云端立即删除。

完整新增状态以 `DESIGN-MANIFEST-v3.json` 为准；“新增”数量按逐画板映射之外的状态统计，准确枚举见 Manifest。

## 删除

- 删除 P0 “我的”中的账号、登录、云同步、订阅和 P1 权益承诺。
- 删除重复的产品首页／训练入口双中心结构，合并为唯一 `P0-HOME`。
- 删除三个并行实时提示页面，统一为每次最多一个提示的 `P0-TRAINING-COACHING`。
- 删除把“没有问题”理解为必须生成建议的表达；无成立问题时 Action List 明确为空。
- 删除 Gemini 可覆盖端侧事实或参与实时判断的任何暗示。

## P0 与 P1 分界

| 维度 | P0 端侧训练 | P1 Gemini 高级复盘 |
|---|---|---|
| 触发时机 | 训练前、训练中、组结束与本地历史 | 仅在训练组结束并保存端侧总结后 |
| 网络 | 核心训练离线可用 | 需要网络 |
| 数据 | 本机结构化结果；视频默认不保存 | 用户同意后上传最小必要数据 |
| 事实权威 | 计数、完整性、成立问题和未判断 | 只能综合解释，不能覆盖端侧事实 |
| 实时能力 | 计数与最多一个教练提示 | 不参与实时计数或实时口令 |
| 商业化 | 无账号、无订阅、无云同步 | 独立权益与 StoreKit 流程 |

## 仍需产品负责人决定

1. P1 的权益形式：单次购买、次数包或周期权益。
2. 正式价格、免费试用或免费额度。
3. 默认关键帧数量上限，以及可选短视频的时长与大小上限。
4. 云端数据默认保留期限和地区化隐私文案。
5. 分析超时、速率限制、额度周期和重试阈值。

上述项目在 v3 中均使用明确的“待产品确认”文案，没有伪造数值。
