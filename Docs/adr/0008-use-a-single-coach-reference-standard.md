# 以一次性单教练审核建立发布参考标准

作为个人开发产品，第一版不建立持续性的多教练标注与仲裁团队。开发者已有的专业教练将作为主要领域专家：参与冻结动作问题定义和标注指南，并在不知道规则、端侧模型或 Gemini 输出的情况下审核冻结测试样本。开发者标注和获得明确许可的专业公开视频可以用于研发、预训练或形成初始标签，但不能作为正式准确率证明；普通公开视频也不能因公开可观看而被假定具有商业训练许可。对外报告的准确率必须表述为与该单一专家参考标准的一致率，同时披露测试人数、样本量、场景范围和置信区间，不得表述为行业共识、医学结论或普适正确率。未来如需提出更强的专业性或安全性主张，再引入第二位独立专家复标与争议仲裁。
