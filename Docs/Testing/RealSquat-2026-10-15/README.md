# 侧面真人深蹲回放：失败复现与修复验证

最新状态：站稳检测修复后，Mac 和 iPhone 真实视频回放均在约第 2 秒建立基线、得到 5 次。详见 [FIX-VALIDATION.md](FIX-VALIDATION.md)。以下保留首次失败证据。

2026-10-15，iPhone 15 Pro Max。使用 App 当前实际视频解码、Apple Vision revision 1 和 `SquatSession`；没有合成关键点、没有调整生产阈值来使视频通过。

## 素材和处理

- 原片：Polina Tankilevitch，Pexels，编号 6525519，1080×1920、30fps、约 6.25 秒，单人、白色背景、侧面徒手深蹲。
- 来源：https://www.pexels.com/video/young-woman-exercising-6525519/
- 许可：https://www.pexels.com/license/ ，页面允许下载、使用和修改。保留出处，不表示作者或模特认可本 App。
- 原片从半次动作开始，自然站立阶段不足约 2 秒，不能直接用来评价自动站稳后的计次准确性。
- 从原片截取 0.9–4.3 秒：人工检查是站立 → 下蹲 → 返回站立的一个完整周期。重复这个片段 5 次，开头定格 3 秒，结尾定格 1 秒，共 21 秒。动作速度不变。这里是同一动作的五次拷贝，不是五次独立真人表现；定格也不能用于评估真人站立时的抖动。
- 分别准备 540×960 版和保留原始 1080×1920 分辨率版，排查缩放是否是唯一原因。哈希和处理参数保存在 `source-and-preparation.json`。

## 实测结果

| 输入 | 解码/姿态帧 | 站立基线 | 人工预期完整周期 | App 次数 |
| --- | ---: | --- | ---: | ---: |
| 原片 | 187 | 未建立 | 站稳条件不满足，不作计次验收 | 0 |
| 加站立定格，540×960 | 630 | 未建立 | 5 | 0 |
| 加站立定格，1080×1920 | 630 | 未建立 | 5 | 0 |

两种分辨率均在真实 iPhone 调用 Vision。第一遍用委托到同一实际 Vision 适配器的记录器，留存关键点和状态；第二遍调用 App 导入按钮使用的 `SquatReplayModel.importFile`，验证临时副本、AVPlayer 和默认生产适配器，结果仍为 0，且没有文件读取或推理错误。没有自动操作 iPhone 的系统文件选择器，文件由开发工具复制进 App 容器后交给同一个导入方法。

当前可确定的阻断点在站稳入口：代码要求同侧肩、髋、膝、踝每个点的置信度至少 0.65。开头 3 秒里，540 版近侧右髋置信度为 0.439–0.442，1080 版为 0.466–0.469；因此即使画面静止、人物完整可见，也无法进入站稳时间窗口。提示仍显示“请让侧面的肩、髋、膝、踝完整入镜”，未准确区分低置信度与未入镜。

这证明当前参数在这段真人素材上无法完成站稳。还没有进入可评价计次准确率的阶段；不能将其归因为“计次状态机漏了 5 次”，也不能据单个样本确定适合所有人的新置信度阈值。

## 证据和复现

- `results/*-result.json`：最终次数及每个回放更新的时间、提示和基线状态。
- `results/*-vision-poses.json`：iPhone 实际 Vision 输出的关键点，可脱离视频反复重放核心规则。
- `results/*-confidence.csv`：逐帧近侧关键点置信度。
- `results/comparison.json`：两种分辨率对照。
- XCTest 结果包 `/tmp/coach-real-video-first.xcresult` 与 `/tmp/coach-real-video-hd.xcresult`。测试 `testSelectedRealSquatVideoReplay` 是显式开启的外部素材验证；两次运行都因预期 5 次/已站稳而实际为 0 次/未站稳失败，未将失败跳过或改写成通过。

手动复现时把 `media` 中的三个视频复制到 App 的 `Documents/replay-validation`。测试运行配置环境变量设 `COACH_REAL_REPLAY_TEST=1`；`COACH_REAL_REPLAY_HD_ONLY=1` 可仅运行 1080 版。默认常规测试会跳过这个需要外部文件的用例。

拍屏对照使用 `index.html`，有全屏播放和回到起点按钮。已验证视频时长 21 秒、1080×1920，可播放；页面已复位为暂停、0 秒。可在 Mac 本地打开页面，或运行：

```sh
python3 -m http.server 8769 --bind 127.0.0.1 --directory Docs/Testing/RealSquat-2026-10-15
```

然后访问 `http://127.0.0.1:8769/`。先固定 iPhone 并打开 App 相机，再从头全屏播放，对比是否建立站稳和最终次数。现阶段这是失败复现片，不是已通过的准确率基准。正常 Debug App 在测试后恢复安装和启动，原有历史保留；回放测试没有保存新的训练记录。
